# RawKit Flutter example

This small application develops the bundled synthetic 64 × 48 Bayer DNG through
RawKit's native worker, displays an 8-bit preview, and renders a full 16-bit RGB
image. It keeps the package itself independent of Flutter.

Generate the standard platform runners once, from this directory:

```console
flutter create --empty --platforms=ios,macos --project-name=rawkit_flutter_example .
flutter pub get
flutter devices
flutter run -d <device-id>
```

The runners and build outputs are generated files and are not committed. The
`--empty` option avoids generating an unrelated counter widget test. The
example requires a native target and is intended for iOS and macOS.

On macOS with Xcode and an installed iOS simulator runtime:

```console
flutter test integration_test/rawkit_test.dart -d <ios-simulator-id>
flutter build ios --release --no-codesign
```

For the macOS integration run:

```console
flutter test integration_test/rawkit_test.dart -d macos
```

The integration harness reuses the package's backend, synthetic DNG, typed
error, image buffer, geometry, tone and preview scheduling tests. It also runs
the original CLI example against a temporary sandbox file, verifies both PPM
outputs, and checks that the Flutter application displays the developed image.
Download/build-tool tests remain in the package's host-only Dart suite.

`assets/sample.dng` is generated by `test/support/synthetic_dng.dart` with width
64, height 48, orientation 1 and a capture time of 2026-10-04 12:00:00 UTC. It is
a test fixture, rather than a camera photograph. The CLI example remains usable
with real RAW files from the package root.
